# 全量配置参数手册 (Configuration Guide)

**EdgeTunnel Gateway** 采用双层配置架构：首次启动时读取 Docker 环境变量作为默认基线；在 Web 控制台进行修改后，数据会实时持久化保存至宿主机挂载的 `config.json`，并支持修改前自动备份快照与随时回滚。

---

## 1. Docker 环境变量清单 (`docker-compose.yml`)

可在容器编排文件中配置以下环境变量：

| 环境变量名 | 默认值 / 示例 | 类型 | 说明 |
| :--- | :--- | :---: | :--- |
| **`PORT`** | `8787` | 整数 | WebSocket (Pages 后端) 代理监听端口 |
| **`H2C_PORT`** | `8788` | 整数 | XHTTP (Worker 后端) 双模自适应代理监听端口 |
| **`WEB_PORT`** | `8789` | 整数 | Web 控制台与 REST API 监听端口 |
| **`PREFERRED_SERVER`** | `cf.example.com` | 字符串 | 默认兜底优选服务器（客户端未传 `prefer` 时生效） |
| **`PAGES_BACKENDS`** | `p1.example.com,p2.example.com` | 逗号分隔 | Pages 真实后端域名列表 |
| **`WORKER_BACKENDS`** | `w1.example.com,w2.example.com` | 逗号分隔 | Worker 真实后端域名列表 |
| **`TRAFFIC_SAMPLE_MINUTES`** | `5` | 整数 | 流量走势图采样频率（单位：分钟） |
| **`CF_PANEL_URL`** | `https://usagepanel.pages.dev` | URL | UsagePanel 镜像地址 |
| **`MEMORY_THRESHOLD_MB`** | `150` | 整数 | 内存自动回收触发阈值（单位：MB） |
| **`MEMORY_INTERVAL_MINUTES`**| `5` | 整数 | 内存健康状态巡检频率（单位：分钟） |
| **`TG_BOT_TOKEN`** | `123456789:ABC...` | 字符串 | Telegram 机器人 Token（留空不推送） |
| **`TG_CHAT_ID`** | `-100123456789` | 字符串 | 接收告警的 Telegram Chat ID |
| **`TG_PROXY`** | `socks5://10.10.10.1:7890` | 字符串 | Telegram API 转发代理（支持 SOCKS5 / HTTP） |
| **`TG_API_HOST`** | `api.telegram.org` | 字符串 | Telegram API 域名（支持反向代理域名） |

## 2. Web 控制台【核心配置】详细说明

登录控制台后，进入 **“核心配置”** 面板可实时修改以下参数：

### ① 基础配置与节点池
- **默认兜底优选 Server**：客户端请求未携带 `prefer` 参数时，出站实际连接的 IP 或域名；
- **走势图采样频率**：控制台顶部历史流量采样间隔（1 ~ 1440 分钟）；
- **Worker / Pages 后端域名列表**：逗号分隔的域名列表，用于轮询分流。

### ② 调度策略
- 网关作为软路由（如 Mihomo / Clash）的上游网关，位于软路由与 Cloudflare 边缘节点之间；
- 软路由向网关发起的出站连接端口具有高随机性，单机 IP 粘性在此拓扑下不适用；
- 调度采用**平权轮询 (Fair Round-Robin)**，新连接严格均匀轮流分派至各健康后端，确保各子账户的免费配额（10 万次/天）均匀消耗。

### ③ 额度统计口径
- **单项协议消耗 (默认)**：
  - Worker 后端卡片仅统计对应子账户的 Worker 额度（免费账户上限 50,000 次/天）；
  - Pages 后端卡片仅统计对应子账户的 Pages 额度（免费账户上限 50,000 次/天）；
- **账户总计消耗**：
  - 汇总统计对应绑定的 Cloudflare 子账户当天全部请求数（免费账户总上限 100,000 次/天）。

### ④ Cloudflare 额度自动避让阈值 (%)
- **默认值**：`95%`（支持 10% ~ 100% 自由设置）；
- **工作机制**：
  - 当某后端绑定的子账户当日配额达到该阈值时，网关自动将该节点移出健康池；
  - 流量平滑转移至未超限的子账户后端；
  - 若全部子账户均达到阈值，网关自动降级保留所有节点继续工作，避免断网。

### ⑤ 后端域名与子账户关联
- 将各 Worker / Pages 域名与特定的 Cloudflare 子账户进行关联映射；
- 映射后，控制台卡片将实时显示对应的子账户名称与额度消耗进度；
- 点击 **“智能推导匹配”**，系统会根据域名与账户名称相似度自动完成映射。

### ⑥ 内存守护与自动回收 (Memory Guard)
- **自动回收开关**：启用或关闭后台自动巡检；
- **触发阈值 (MB)**：常驻物理内存达到设定值（默认 150MB）时，触发深度清理与 V8 原生垃圾回收；
- **巡检频率 (分钟)**：后台巡检间隔（默认 5 分钟）；
- **V8 GC 状态**：显示当前环境是否包含 `--expose-gc` 参数。

## 3. 历史配置快照与回滚

每次在 Web 控制台点击 **“保存配置”** 时，系统会自动执行快照备份：
1. **自动生成快照**：旧配置自动保存至 `config_backups/config_backup_<时间戳>.json`；
2. **滚动清理**：系统保留最新的 **5 份快照**，超出部分自动删除；
3. **一键回滚**：
   - 在核心配置页面下方的快照列表中，可查看快照生成时间与后端数量；
   - 点击 **“恢复此快照”** 即可回退配置并即时生效。

## 4. 管理员认证安全

- **密码加密**：采用 **SHA-256 + 16 字节随机盐 (Salt)** 单向哈希存储；
- **会话 Token**：登录成功后生成 32 字节随机 Bearer Token，有效期 7 天；
- **首次配置**：系统无默认硬编码密码，首次访问强制引导用户初始化设置；
- **密码修改**：在“核心配置”页面可校验旧密码并设置新密码。
