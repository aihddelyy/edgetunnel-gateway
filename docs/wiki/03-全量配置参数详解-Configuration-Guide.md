# ⚙️ 全量配置参数手册 (Configuration Guide)

**EdgeTunnel Gateway** 支持**双层配置架构**：初次启动时从 Docker 环境变量加载默认基线，后续在 Web 控制台的任何修改均会持久化保存至宿主机挂载的 `config.json`，并支持修改前自动快照备份与随时一键回滚。

---

## 📋 1. Docker 环境变量清单 (`docker-compose.yml`)

以下环境变量可在容器编排文件中指定：

| 环境变量名 | 默认值 / 示例 | 类型 | 详细作用说明 |
| :--- | :--- | :---: | :--- |
| **`PORT`** | `8787` | 整数 | WebSocket (Pages 后端池) 专属反代监听端口 |
| **`H2C_PORT`** | `8788` | 整数 | XHTTP (Worker 后端池) 首包嗅探双模监听端口 |
| **`WEB_PORT`** | `8789` | 整数 | Web 控制台与 REST API 监听端口 |
| **`PREFERRED_SERVER`** | `cf.example.com` | 字符串 | 默认兜底优选服务器（当客户端请求未携带 prefer 时生效） |
| **`PAGES_BACKENDS`** | `p1.example.com,p2.example.com` | 逗号分隔 | 真实 Cloudflare Pages 后端域名池（可填多个，用于轮询） |
| **`WORKER_BACKENDS`** | `w1.example.com,w2.example.com` | 逗号分隔 | 真实 Cloudflare Worker 后端域名池（可填多个，用于轮询） |
| **`TRAFFIC_SAMPLE_MINUTES`** | `5` | 整数 | 监控中心 XHTTP/WS 迷你走势波形图历史采样间隔（分钟） |
| **`CF_PANEL_URL`** | `https://usagepanel.pages.dev` | URL | UsagePanel 原版额度面板镜像地址 |
| **`MEMORY_THRESHOLD_MB`** | `150` | 整数 | Memory Guard 自动内存回收触发阈值（物理内存 MB） |
| **`MEMORY_INTERVAL_MINUTES`**| `5` | 整数 | 后台内存健康状态巡检频率（分钟） |
| **`TG_BOT_TOKEN`** | `123456789:ABC...` | 字符串 | Telegram 机器人 Bot Token（为空则关闭推送） |
| **`TG_CHAT_ID`** | `-100123456789` | 字符串 | 接收预警通知的 Telegram Chat ID 或频道 ID |
| **`TG_PROXY`** | `socks5://10.10.10.1:7890` | 字符串 | Telegram API 转发代理（直连内网旁路由出境，支持 SOCKS5 / HTTP） |
| **`TG_API_HOST`** | `api.telegram.org` | 字符串 | Telegram 官方 API 服务器域名（可自定义为反代反向域名） |

## 🖥️ 2. Web 控制台【核心配置】详细参数解析

登录 Web 控制台后，进入 **“⚙️ 核心配置”** 选项卡，可在网页端即时修改并保存以下各项核心参数：

### ① 基础参数与分流后端池
- **默认兜底优选 Server**：当遇到未清洗出 `prefer` 的裸节点请求时，网关出站建立物理 TLS 连接的兜底目标；
- **流量走势图采样频率**：控制监控中心顶部折线图的历史采样颗粒度（1 ~ 1440 分钟）；
- **Worker / Pages 后端域名列表**：以英文逗号分隔的多域名列表，网关在转发时自动在此集合中执行平权轮询。

### ② 分流调度策略 (绝对平权雨露均沾轮询)
- **架构定位与纯粹平权**：
  - 本分流网关专职作为 **Mihomo / Clash 等软路由内核的上游负载均衡网关**，位于软路由与 Cloudflare 边缘节点之间，并不承担面向终端设备的直接分流代理，不会有单机设备直接连接网关；
  - 软路由 (如 Mihomo) 发往网关的出站代理连接端口具有高随机性，因此传统的单机 IP 会话粘性机制在此拓扑下不起作用。网关彻底去除冗余的粘性状态机，全面采用**轻量高效的原子平权轮询 (Fair Round-Robin)**；
- **核心效益**：
  - 每一个新的代理连接均严格均匀轮流分派至各个健康的 Worker / Pages 后端，使各 Cloudflare 账号的免费配额（10万次/日）获得最精准、最公平的平摊；
  - 在单连接内部，依托底层 **双向流式零拷贝管道、TCP NoDelay/KeepAlive、16MB HTTP/2 动态大窗口以及独创的 H2 会话池弹性复用** 技术，确保流媒体视频与大文件测速瞬时达到极限满速。

### ③ 监控中心额度统计口径
- **🔹 单项协议消耗 (默认)**：
  - Worker 后端卡片仅统计并消耗对应账户的 Worker 额度（免费账户上限 50,000 次/天）；
  - Pages 后端卡片仅统计并消耗对应账户的 Pages 额度（免费账户上限 50,000 次/天）；
- **🔸 账户总计消耗**：
  - 汇总统计对应绑定的 Cloudflare 子账户下当天的全部请求总数（免费账户总上限 100,000 次/天）。

### ④ Cloudflare 额度自动避让阈值 (%)
- **默认值**：`95%`（支持 10% ~ 100% 自由设定）；
- **工作机制**：
  - 当某后端绑定的子账户当天配额消耗达到该阈值时，网关动态调度时会自动将该节点**移出健康可用池**；
  - 流量将平滑由其他剩余健康账户承接；
  - **防止断网降级兜底**：若全部子账户均达到或超过阈值，网关会自动降级保留全部节点继续轮询，确保网络绝不中断。

### ⑤ 后端域名与 Cloudflare 子账户关联绑定
- 将各个具体的 Worker / Pages 域名与特定的 Cloudflare 子账户进行 1 对 1 关联绑定；
- 绑定后，监控中心的卡片将直接实时显示该节点对应的子账户名称、当日请求消耗柱状进度条与百分比；
- **⚡ 智能推导匹配**：点击此按钮，系统会根据后端域名中的前缀字符与已配置的 CF 账户名称进行智能相似度推导，自动完成映射绑定！

### ⑥ 🧠 内存自动回收与治理守护 (Memory Guard)
- **自动回收开关 (Toggle)**：开启或关闭后台自动巡检；
- **触发阈值 (MB)**：网关常驻物理内存达到该数值（默认 150MB）时，系统自动执行深度清理与 V8 原生 GC；
- **巡检频率 (分钟)**：后台巡检周期（默认 5 分钟）；
- **V8 GC 支持状态徽章**：实时显示当前运行环境中是否已注入 `--expose-gc` 原生参数。

## 📦 3. 历史配置快照与一键回滚机制

每次在 Web 控制台点击 **“💾 保存配置”** 时，网关会在后台自动触发快照机制：
1. **自动生成快照**：将当前旧配置保存至宿主机挂载的 `config_backups/config_backup_<时间戳>.json`；
2. **滚动淘汰**：系统自动维持最多 **5 份最新历史快照**，超出部分自动清理，绝不浪费磁盘空间；
3. **一键回滚**：
   - 在核心配置最下方 **“📦 历史配置快照与一键回滚”** 区域；
   - 点击 **“🔄 刷新快照”** 即可查阅各快照生成的精确时间点与后端数量简报；
   - 点击 **“↺ 恢复此快照”**，网关将完成原子回滚并即时热生效，彻底消除配置误操作带来的风险！

## 🔐 4. 管理员认证安全

- **密码加密算法**：基于 Node.js 原生 `crypto`，采用标准 **SHA-256 + 16 字节随机盐 (Salt)** 单向哈希加密存储；
- **会话机制**：登录成功后下发 32 字节高强度随机 Bearer Token，默认有效期 7 天；
- **无密码首次引导**：系统首次部署时无需任何默认硬编码密码，首次访问强制要求用户自行初始化，消除弱口令安全隐患；
- **修改密码**：在“核心配置”页面随时可校验旧密码并设定新密码。
